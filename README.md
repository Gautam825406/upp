# U++ Academy — website

Public website for **U++ Academy**, a coaching academy in Madhygopali, Maharajgunj
(Jharkhand), serving students from Maharajgunj, Madhygopali and nearby Chouparan.

- **Classes:** 6 to 12 — Class 6–10 across boards, Class 11–12 Arts & Science
- **Boards:** JAC, CBSE, ICSE
- **Director:** Umesh Kumar
- **Contact:** +91 9065792628 (call / WhatsApp)
- **Live domain:** https://uppacademy.in/

## Stack

React 19 + Vite + TypeScript + Tailwind CSS. No backend — the admission enquiry
form opens WhatsApp with the enquiry details; nothing is stored on a server.

Pages are prerendered at build time (`scripts/prerender.mjs`), so every route ships
as static HTML with correct title, meta description, canonical URL, Open Graph
tags and JSON-LD. The sitemap is generated by `scripts/generate-sitemap.mjs`.

## Run it

```sh
npm install
npm run dev        # local dev server
npm run typecheck  # tsc --noEmit
npm run build      # vite build + prerender (writes dist/)
npm run seo:check  # verify sitemap matches the route manifest
```

## Content rules

Only verified facts are published on this site. There are no testimonials, ratings,
student counts, fees, timetables, or teacher qualifications anywhere in the code,
because none were verified — do not add them without confirmation from the academy.

- Contact details live in one place: `src/data/business.ts`.
- Class range and boards live in `src/data/courses.ts`.
- FAQs in `src/data/faqs.ts` are shown on the page *and* emitted as FAQPage
  structured data — keep the two in sync (they share the same source).
- `public/logo.jpg` is the academy's official logo; `public/umesh-kumar.webp`
  is the director's real photograph. Do not replace them with stock images.
